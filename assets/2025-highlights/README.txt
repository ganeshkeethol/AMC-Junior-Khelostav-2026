2025 Highlights Photo Gallery

Add up to 20 real 2025 event photos here using these filenames:
photo-01.jpg through photo-20.jpg

The Highlights page displays 5 carousel slides, with 4 photos on each slide.
The loader also accepts .jpeg/.JPG/.JPEG and will try those variants automatically.

IMPORTANT for GitHub Pages: the photo files must be uploaded into this exact folder in the published website repository:
website/assets/2025-highlights/

Recommended format: JPG, landscape or portrait; the site uses object-fit: cover.
